# Shipped

A workshop on feature adoption. Bilingual (English / Polish).

---

## English

### What this is

A workshop where you act as a Senior PM at a fictional SaaS called Shipped. Your job: figure out which features in the product have an adoption problem and what to do about them. You go through the same process a PM uses on real features: look at adoption, ask what the feature is for, check if it delivers value, decide what to do, and build a hypothesis if you're shipping a fix.

### What's in this repo

Everything you need to play the role: the company context, its 9 features, the data behind each one (funnels, retention, user quotes), and three cases to diagnose. You don't read the files yourself. You open the repo in Claude Code, and Claude does the work: pulls data on request, walks you through the flow, pushes back when you try to skip a step.

### How to start

1. Clone or download this repo.
2. Open the folder in Claude Code.
3. Type anything (`hi`, `start`, or a question).
4. Pick a language and a path (guided intro or jump straight to a case).

## Polski

### O co chodzi

Warsztat, w którym wcielasz się w Senior PM-a fikcyjnego SaaS-a o nazwie Shipped. Twoje zadanie: zdiagnozować, które funkcjonalności w produkcie mają problem z adopcją i co z tym zrobić. Przechodzisz przez ten sam proces, którego PM używa na realnych ficzerach: spójrz na adopcję, sprawdź czy feature ma rolę biznesową, zweryfikuj czy daje wartość, podejmij decyzję, zbuduj hipotezę jeśli wdrażasz fix.

### Co jest w repo

Wszystko, czego potrzebujesz, żeby wejść w rolę: kontekst firmy, 9 funkcjonalności, dane (lejki adopcji, retencja, cytaty userów) i trzy case'y do diagnozy. Nie czytasz plików samodzielnie. Otwierasz repo w Claude Code i Claude robi robotę: podaje dane na żądanie, prowadzi cię przez flow, pyta dalej gdy próbujesz pominąć krok.

### Jak zacząć

1. Sklonuj albo pobierz repo.
2. Otwórz folder w Claude Code.
3. Napisz cokolwiek (`cześć`, `start`, albo od razu pytanie).
4. Wybierz język i ścieżkę (prowadzone intro albo skok do case'a).
